ESP32 Ventilation Control Unit

During my internship at Ecomotive Development, I designed and built an intelligent ventilation control system. The goal was to create an autonomous solution that monitors indoor and outdoor conditions and regulates airflow based on temperature and humidity levels.

Project overview

The system was built around an ESP32 microcontroller and used multiple sensors to collect environmental data. It measured the indoor and outdoor temperatures, tracked relative humidity, and adjusted a ventilation relay according to user-defined thresholds. The result was a compact, energy-efficient control unit designed for real-world use.

What I worked on

  • Developed the firmware in C++ using the Arduino environment.
  • Integrated DS18B20 temperature sensors and a DHT11 humidity sensor.
  • Implemented logic for automatic control, hysteresis, safety checks, and debounce handling.
  • Designed and assembled the enclosure and front panel based on measured hardware dimensions.
  • Added a small LCD display to show live values and system status.

Key components

  • ESP32 microcontroller
  • DS18B20 temperature sensors
  • DHT11 humidity sensor
  • 16x2 I2C LCD display
  • Potentiometer control input
  • Relay output module
  • Manual operating switches
  • Custom CNC-machined enclosure

Challenges and learning

This project gave me practical experience in embedded systems, hardware integration, and debugging. I had to solve real engineering issues such as sensor failures, display flicker, signal noise, and stable switching behavior. The final outcome improved my understanding of how software, electronics, and mechanical design work together in a complete product.
